# Retail Sales Data Analyzer

Retail Sales Data Analyzer is a simple Python project used to analyze retail sales data from a CSV file. It uses Pandas and NumPy for data analysis and Matplotlib and Seaborn for data visualization.

## Features

- Load retail sales data from a CSV file
- Check required columns in the dataset
- Handle missing values
- Clean the data
- Calculate sales metrics
- Find total sales
- Find average sales
- Find the most popular product
- Find the best selling category
- Filter data by category
- Filter data by date range
- Display a sales summary
- Display cleaned data
- Create a bar chart
- Create a line graph
- Create a heatmap
- Interactive menu for the user

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Required CSV Columns

The CSV file should contain the following columns:

- Date
- Product
- Category
- Price
- Quantity Sold
- Total Sales

Date,Product,Category,Price,Quantity Sold,Total Sales
